# 👨‍💻 Arnab Sadhukhan — Developer Portfolio

> A modern, responsive personal portfolio website built with HTML, CSS, and JavaScript.

## 🌐 About

This is my personal developer portfolio where I showcase my skills, projects, education, and interests in technology.

The website features a modern dark-themed design with an animated coding background, responsive layout, smooth scrolling, interactive navigation, and a professional hero section.

- 🎨 Modern dark-themed UI
- 📱 Fully responsive design
- 💻 Animated code background
- ⚡ Smooth scrolling
- 🔥 Typing animation
- 🧭 Responsive navigation menu
- 👨‍💻 Skills showcase
- 🚀 Projects section
- 🎓 Education timeline
- 📩 Contact section
- ⬆️ Back-to-top button
- ✨ Scroll reveal animations
